# Codex template

`mcp.example.json` remains an unverified native configuration template. Local MCP tools are service-backed and SDK-tested, but this template is not a native compatibility claim.

The separate [`codex-exec-v1` session adapter](../../docs/safe-capture-and-sessions.md) is verified on Windows with Codex `0.162.0-alpha.17.2`. It acknowledges context before task release and captures versioned learning/no-learning outputs in read-only mode. It uses stdin JSON and constrained final output, not this MCP template. Installation owns only knowledge-runtime adapter files and leaves native/global client settings untouched.
